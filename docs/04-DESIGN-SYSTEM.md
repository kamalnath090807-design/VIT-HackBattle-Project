## Responsive Design

The application must be usable on:

- Mobile
- Tablet

## UI Rules

1. Maintain visual consistency.
2. Do not create duplicate components unnecessarily.
3. Reuse the defined design system.
4. Keep interactions predictable.
5. Provide loading, success, empty, and error states.
6. Prioritize usability over decorative complexity.
